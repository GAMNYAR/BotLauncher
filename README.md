## 📖 Документация

### 🚀 Быстрый старт (за 5 минут)

#### Шаг 1: Создание бота в Telegram
1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Придумайте имя бота (например, `My Helper Bot`)
4. Придумайте username бота (должен заканчиваться на `bot`, например, `my_awesome_bot`)
5. **Сохраните токен**, который выдаст BotFather (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

#### Шаг 2: Подключение бота к программе
1. Запустите **BotLauncher**
2. Перейдите во вкладку **Telegram** (иконка самолётика слева)
3. В поле **"Токен бота"** вставьте полученный токен
4. Нажмите **"Подключить"**
5. Если всё верно — статус изменится на **"Подключено"** (зелёная галочка)

#### Шаг 3: Добавление групп или каналов
1. Добавьте вашего бота в нужные группы или каналы **как администратора** (с правами на отправку сообщений)
2. В программе перейдите во вкладку **Группы**
3. Нажмите **"+ Добавить группу или канал"**
4. Введите username группы (например, `@my_group`) или её числовой ID
5. Нажмите **"Добавить"**

#### Шаг 4: Создание шаблона сообщения
1. Перейдите во вкладку **Шаблоны**
2. Нажмите **"Создать шаблон"**
3. Заполните поля:
   - **Название:** `Приветствие`
   - **Текст сообщения:** 
     ```html
     <b>Привет!</b>
     
     Это <i>тестовое сообщение</i> с <a href="https://github.com/GAMNYAR/BotLauncher">ссылкой</a>
     
     <blockquote>Здесь поддерживается HTML-разметка Telegram</blockquote>
     ```
4. *(Опционально)* Прикрепите фото, видео или документ кнопкой **"Добавить вложение"**
5. Нажмите **"Сохранить"**

#### Шаг 5: Отправка сообщения
1. Перейдите во вкладку **Группы**
2. Выберите нужную группу из списка слева
3. Перейдите на вкладку **"Ручной"** (в верхней части окна)
4. В выпадающем списке выберите созданный шаблон `Приветствие`
5. Нажмите кнопку **"Отправить сейчас"**
6. Готово! Сообщение успешно отправлено в группу.

### 📚 Подробное описание вкладок

#### 🤖 Вкладка "Telegram"
Здесь происходит управление подключением бота.
- **Токен бота:** обязательное поле для авторизации через Telegram API.
- **Кнопки:** "Подключить", "Отключить", "Проверить статус" (показывает имя бота и его ID).

#### 👥 Вкладка "Группы"
Управление списком чатов для рассылки.
- Отображает название, тип (группа/канал), количество участников и статус.
- Позволяет добавлять новые чаты по username или ID.
- Содержит подвкладки режимов отправки: **Ручной**, **Автоматический**, **Отложенный**, **Периодический**, **По событию**.
> ⚠️ **Важно:** На данный момент (v1.0) полностью стабилен и готов к использованию только **"Ручной"** режим. Остальные находятся в активной разработке.

#### 📝 Вкладка "Шаблоны"
Конструктор сообщений.
- **Текст:** до 4096 символов с поддержкой HTML-тегов Telegram.
- **Вложения:** поддержка изображений, видео, документов и аудиофайлов.
- **Динамические переменные:** `{date}` (дата), `{time}` (время), `{datetime}` (дата и время), `{day}` (день недели).

**Поддерживаемые HTML-теги:**
- `<b>жирный</b>` — жирный текст
- `<i>курсив</i>` — курсив
- `<u>подчёркнутый</u>` — подчёркнутый текст
- `<s>зачёркнутый</s>` — зачёркнутый текст
- `<a href="ссылка">текст</a>` — гиперссылка
- `<blockquote>цитата</blockquote>` — оформление в виде цитаты (блок)

#### ⚙️ Вкладка "Ручной режим"
Основной инструмент для отправки с тонкой настройкой.
- **Основные:** выбор шаблона, ввод дополнительного пользовательского текста, порядок отправки (что первым: шаблон или текст).
- **Тайминг:** задержка перед отправкой, автоудаление сообщения через заданное время.
- **Оформление:** скрытие текста под спойлер, защита от копирования/пересылки, тихая отправка (без звука), отключение предпросмотра ссылок.
- **Действия:** закрепление сообщения в чате, удаление предыдущего сообщения бота, ответ на последнее сообщение в чате (Reply).
- **Интерактив:** отправка анимированных смайликов (🎲, 🎯, 🏀) и автоматическая постановка реакций (👍, ❤️, 🔥).
- **Уведомления:** всплывающие уведомления об успехе или ошибке отправки.

- Умные шаблоны сообщений с поддержкой HTML и переменных

- Веб-интерфейс для управления с телефона

## ⚙️ Системные требования

- **Операционная система:** Windows 10 / 11 (64-bit)
- **Процессор:** 1 GHz или выше
- **Оперативная память:** 2 GB RAM (рекомендуется 4 GB)
- **Место на диске:** ~500 MB
- **Зависимости:** .NET 8.0 Runtime

> Если при запуске появляется ошибка об отсутствии .NET, скачайте и установите **".NET Desktop Runtime 8.0"** с [официального сайта Microsoft](https://dotnet.microsoft.com/download/dotnet/8.0).

## ❓ Часто задаваемые вопросы (FAQ)

**Q: Программа не запускается, ничего не происходит.**  
**A:** Убедитесь, что у вас установлен **.NET 8.0 Desktop Runtime**. Это самая частая причина проблем на Windows 10.

**Q: Бот не подключается, выдаёт ошибку.**  
**A:** 
1. Проверьте правильность введённого токена (без лишних пробелов).
2. Убедитесь, что бот не был удалён или заблокирован через @BotFather.
3. Проверьте стабильность интернет-соединения.

**Q: Сообщения не отправляются в группу.**  
**A:** Бот обязательно должен быть добавлен в группу или канал **как администратор** с правами на отправку сообщений.

**Q: Как обновить программу до новой версии?**  
**A:** Просто скачайте новый установщик из раздела [Releases](https://github.com/GAMNYAR/BotLauncher/releases) и запустите его. Он автоматически обновит файлы поверх старой версии.
