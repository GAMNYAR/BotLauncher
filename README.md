# 🪰 BotLauncher

Мощная программа для автоматизации Telegram-ботов, созданная с нуля. Проект родился спонтанно: я просто хотел облегчить себе рутинную работу с YouTube и в моменте придумал этот инструмент.

> **Статус:** Проект активно развивается! Название пока рабочее.

## ✨ Что уже умеет приложение:
- ✅ Умные шаблоны, отложенный постинг, автоудаление сообщений
- ✅ Спойлеры, защита от копирования, тихая отправка
- ✅ Анимированные реакции и эмодзи (Dice)
- ✅ История отправок и автовосстановление сессий после сбоев
- ✅ Поддержка медиафайлов (фото, видео, документы)
- ✅ HTML-разметка (жирный, курсив, ссылки, цитаты)
- ✅ Закрепление сообщений в чатах

## 🎯 Планы на будущее:
- 🔹 Полноценная интеграция с YouTube
- 🔹 Поддержка ответов в личные сообщения пользователям
- 🔹 Управление несколькими ботами одновременно

## 🚀 Как начать использовать:
1. Перейдите в раздел **[Releases](https://github.com/GAMNYAR/BotLauncher/releases)** справа.
2. Скачайте последнюю версию программы (`BotLauncher_v1.0.zip`).
3. Распакуйте архив в любую папку.
4. Запустите `BotLauncher.exe`.
5. Введите токен вашего Telegram-бота в настройках.

## ⚠️ Требования:
- Операционная система: **Windows**
- .NET 8.0 (скачать: https://dotnet.microsoft.com/download)
